حزمة ملفات مجلس القمة - F90
================================

المحتويات:
- index.html : الصفحة الرئيسية
- style.css : التصميم المتجاوب
- script.js : الحاسبات والسجل وإدارة العملات
- manifest.json : تعريف تطبيق PWA
- sw.js : التخزين المؤقت والعمل دون اتصال بعد أول زيارة
- icon.svg : أيقونة التطبيق

طريقة الرفع اليدوي:
1) افتح مستودع GitHub: F90xd/F90
2) افتح فرع main أو أنشئ فرعاً جديداً للمراجعة.
3) ارفع الملفات الستة إلى جذر المشروع، مع استبدال الملفات التي تحمل الأسماء نفسها.
4) اضغط Commit changes.
5) انتظر تحديث GitHub Pages ثم افتح:
   https://f90xd.github.io/F90/

تنبيه مهم:
- قبل الاستبدال، نزّل نسخة احتياطية من الملفات القديمة.
- سجلات VIP القديمة تستخدم مفتاح التخزين majlis_alqimma_vip_records_v5 وتبقى محفوظة محلياً على الجهاز نفسه.
- أسعار العملات تحفظ في majlis_alqimma_currencies_v1.
- الأسعار الافتراضية للتارجت: 73 JOD / 100 USD / 5800 EGP لكل مليون.
- الأسعار الافتراضية للألعاب: 62 JOD / 85 USD / 4500 EGP لكل مليون.
- أسعار VIP الافتراضية: JOD 11 / USD 15 / EGP 1 / TRY 800 لكل وحدة دعم.
- تمت المحافظة على جدول VIP وقاعدة حساب نقاط الترقية والتثبيت الموجودة في النسخة السابقة.
- لا توجد قاعدة بيانات أو مزامنة بين الأجهزة؛ التخزين محلي في المتصفح.

اختبار:
