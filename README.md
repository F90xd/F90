# مجلس القمة للشحن

حاسبة VIP والشحن وصافي الحساب — موقع شخصي يعمل بالكامل من المتصفح، بدون أي خادم أو قاعدة بيانات خارجية أو تسجيل دخول.

## التشغيل

```bash
npm install
npm run dev
```

يفتح الموقع افتراضيًا على `http://localhost:5173`.

## البناء للإنتاج

```bash
npm run build
```

تُنشأ الملفات النهائية داخل مجلد `dist/`. يمكن معاينتها محليًا عبر:

```bash
npm run preview
```

## الفكرة الأساسية للحاسبة

هذه الحاسبة **لا** تعتمد على جمع "إجمالي الشحن" أو "XP الترقية" من جدول VIP.

المستخدم يستلم صورة حساب العميل ويرى بنفسه كم ينقصه للوصول لكل مستوى، ثم يُدخل هذه القيمة ("الناقص")
يدويًا لكل انتقال بين مستوى وآخر. الموقع يجمع هذه القيم فقط:

```
إجمالي الوصول = مجموع الناقص الذي يُدخله المستخدم يدويًا لكل انتقال
الشحن الفعلي  = إجمالي الوصول ÷ عرض الشحن
```

عند اختيار "مع تثبيت"، تُضاف قيمة عمود "الحفاظ/التثبيت" الخاصة بالمستوى **المستهدف فقط** (لا يُجمع تثبيت
كل المستويات الوسيطة):

```
الإجمالي مع التثبيت = إجمالي الوصول + تثبيت المستوى المستهدف
الشحن الفعلي مع التثبيت = الإجمالي مع التثبيت ÷ عرض الشحن
```

## التخزين المحلي

جميع البيانات (الإعدادات، جدول VIP، العملاء، سجل العمليات) تُحفظ في `localStorage` الخاص بالمتصفح،
ولا تُرسل إلى أي خادم. يمكن تصدير نسخة احتياطية بصيغة JSON واستيرادها لاحقًا من قسم الإعدادات، وكذلك
مسح جميع البيانات المحفوظة عند الحاجة.
